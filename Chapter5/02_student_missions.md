# PyMySQL 偵探教室：消失的黃金吐司

## 案情

2026 年 8 月 20 日 21:25，保全發現珍貴的「黃金吐司」從二樓保管庫 R03 消失。系統沒有遭到外部入侵，因此犯人極可能就在十二名關係人之中。門禁初步顯示，當晚共有七人成功進入 R03；學生必須先重建整晚時間線，再從案發區間與其他證據逐步排除無關訪客。

你的任務不是猜答案，而是用 SQL 查出證據。每一關都要保留：SQL、查詢結果、你的推論。

## 規則

- 只能依資料庫中的紀錄推理。
- `DENIED` 表示門禁失敗，不能視為進入房間。
- 監視器辨識有 `confidence`，數字越接近 1 越可信。
- 刪除訊息並未真的消失，鑑識人員已復原在 `messages` 表中。

## 任務卡

### 第一關：熟悉案情（SELECT）

1. 查詢 `case_brief`。
2. 列出所有房間的名稱與樓層。

### 第二關：重建整晚訪客名單（WHERE / BETWEEN / ORDER BY）

1. 找出 `2026-08-20 18:00:00` 到 `22:00:00` 的所有成功門禁紀錄，依時間排序。這是展覽開放與案發所在的同一個晚上。
2. 在上述晚間區間內，找出曾以 `IN + SUCCESS` 進入 R03 的人員編號；依進入時間排序，查詢應回傳七筆。注意：`DENIED` 不算成功進入。

### 第三關：比對人型與非人型足跡（AND / OR / BETWEEN）

1. 鑑識結果依外型將足跡分成兩類：人型鞋印為 `humanoid_min ~ humanoid_max`，非人型足跡為 `nonhumanoid_min ~ nonhumanoid_max`。使用 `is_humanoid`與兩組`BETWEEN` 查詢符合各自區間的角色。
2. 再加入 `has_orange_trace = TRUE`，找出同時符合足跡與橘色痕跡的人。

### 第四關：串連資料（JOIN）

1. 哪些人的監視器攜帶物與消費品項相同？請連接監視器、消費紀錄與人員資料。查詢應回傳五筆、四位不同人員；其中一人會在不同時間出現兩次。網頁答案請輸入四位不重複人名，順序不限。

### 第五關：數位鑑識（LIKE / JOIN / deleted flag）

1. 找出所有已刪除的訊息。
2. 搜尋內容包含「斷電」、「線路」、「保溫袋」或「巡邏」的訊息，顯示寄件者、收件者與 `is_deleted`。查詢應回傳九筆，其中四筆已刪除。
3. 從四筆已刪除的關鍵字訊息中，整理出三位不同寄件者；網頁答案請輸入三位人名，順序不限。再對照 `evidence`：當晚配電室真的斷電了嗎？保管庫鏡頭為何沒拍到畫面？

### 最終關：寫出逮捕令（多表 JOIN 或子查詢）

1. 寫出一條 SQL，同時滿足以下條件，找出唯一嫌犯：
   - 足跡尺寸符合第三關的人型／非人型區間。
   - 具有橘色痕跡，符合現場橘色纖維。
   - 在案發區間成功進入 R03。
   - 監視器拍到其攜帶銀色保溫袋。
   - 曾購買銀色保溫袋。

## 加分挑戰

1. 用 `GROUP BY` 統計每人成功刷卡的次數，找出次數最多者。
2. 用 `LEFT JOIN` 找出完全沒有被監視器辨識到的人。
3. 使用 `%s` 參數化查詢，讓使用者輸入房間編號與起訖時間；禁止用 f-string 拼接 SQL。
4. 把最終查詢包成 Python 函式 `find_prime_suspect(connection)`。
